# 말씀유산 기능 인벤토리와 회귀 테스트 기준

이 문서는 현재 제품 동작의 기준선이다. 기능을 추가하거나 정책을 변경할 때 먼저 이 문서와 테스트를 갱신하고, 실패하는 테스트를 확인한 뒤 구현한다.

## 1. 홈과 전역 탐색

- 사이트 진입 및 새로고침 시 항상 홈에서 시작한다.
- 홈에서 라이트/다크 모드를 전환하며 선택은 브라우저에 유지된다.
- 홈에서 `말씀 선물하기`, `성경 읽기`, `매일 말씀 읽기 시작하기`, `내 말씀 여정`, `내 카드 보관함`으로 이동한다.
- `말씀 선물하기`는 홈의 큰 메인 메뉴로 표시한다.
- 앱 상단과 모바일 하단에서 홈, 녹음, 듣기, 선물, 친구로 이동한다.
- `내 말씀 여정`에는 실제 녹음이 하나 이상 남은 여정만 표시한다.

## 2. 말씀 여정

- 1주/2주 템플릿과 초급·중급·고급 분량을 선택한다.
- 직접 성경 범위와 여정 이름을 정해 맞춤 여정을 만든다.
- 같은 여정의 전체 일정과 날짜별 완료 상태를 확인한다.
- 매일 읽기는 하루에 최대 한 단계만 진행한다.
- 오늘 분량이 미완료면 다음 날짜에도 같은 분량이 유지되고 이후 일정과 종료일이 밀린다.
- 오늘 완료해도 같은 날 다음 분량으로 넘어가지 않고 다음 날짜에 전환된다.

## 3. 자유 녹음과 성경 선택

- 구약 39권/신약 27권과 총 66권 전체를 탐색하고 검색한다.
- 책, 장을 선택하고 본문 전체를 미리 확인한 뒤 녹음을 시작한다.
- 진행 중인 장을 별도 스타일로 표시한다.
- 같은 성경책의 여러 장은 하나의 `○○ 녹음` 여정으로 묶는다.
- 내 말씀 여정에서 책을 열면 책 선택 없이 해당 책의 장만 선택하고 확인 후 녹음 화면으로 이동한다.
- `성경 읽기`의 한 장 읽기와 범위 지정은 날짜·일차·완료 기간이 없는 자유 읽기로 저장한다.

## 4. 녹음

- 기본 녹음은 현재 절부터 이어 녹음이다.
- `다음 절`로 경계를 기록하고 `여기까지 녹음`하면 현재 절까지 저장한다.
- 이어 녹음 결과를 절별 파일로 잘라 저장한다.
- 이어 녹음으로 기존 절에 진입하면 해당 절 녹음을 새 결과로 덮어쓴다.
- 저장된 절은 개별 듣기와 `이 절 수정`을 제공한다.
- 절별 수정은 확인 없이 기존 파일을 즉시 삭제하고 같은 절 재녹음으로 진입한다.
- 현재 장 전체 새 녹음은 삭제 확인 후 모든 절을 지우고 1절부터 시작한다.
- 녹음 중 마이크 권한, 지원하지 않는 브라우저, 저장 실패 상태를 안내한다.
- 모바일 녹음을 위해 Opus 우선 포맷을 사용하고 목소리는 별도 리버브 없이 원음으로 저장한다.

## 5. 음향과 BGM

- BGM 없음 및 여러 BGM을 선택하고 미리 듣는다.
- 재생·일시정지·정지는 각각 상태가 구분되며 정지 후 재생은 처음부터 시작한다.
- 녹음 중 BGM이 재생 중이면 이어폰 사용 경고를 제공한다.
- BGM 볼륨을 녹음 화면과 이어듣기 화면에서 조절한다.

## 6. 듣기 보관함

- 여정에 속한 녹음만 책/장/절 단위로 묶어 표시한다.
- 절별 듣기는 목소리만 재생한다.
- 자유 읽기는 장 단위로, 매일 말씀 읽기는 여정 전체를 날짜와 말씀 순서대로 이어듣는다.
- 재생 목록은 각 녹음을 책·장·절로 구분하며 재생 모달의 본문도 절에 맞춰 바뀐다.
- 이어듣기 목록 아이콘으로 녹음된 절을 열고 원하는 절로 점프한다.
- 이어듣기 중 BGM 선택, 볼륨 조절, 정지가 가능하다.
- 다음 미녹음 절로 포커스하고 장/절 목록도 해당 위치를 보여준다.

## 7. 녹음 데이터와 보안 경계

- 검증된 로그인 사용자 ID로 보관함 목록, 재생, 교체, 삭제 권한을 분리한다.
- 녹음 메타데이터는 D1, 음성 파일은 R2에 저장한다.
- 같은 여정·책·장·절에 새 파일을 저장하면 기존 파일을 원자적으로 교체한다.
- 한 파일은 최대 25MB이며 잘못된 장·절·본문은 거부한다.
- 오디오 응답은 비공개·비캐시 헤더를 사용한다.

## 8. 말씀 카드

- 매일 말씀 분량 완료 시 말씀 카드를 지급한다.
- 자유 녹음은 보상 대상이 아니며 매일 말씀 여정에만 지급한다.
- 같은 여정의 같은 일차에는 카드를 한 번만 지급한다.
- 아직 받지 않은 카드를 우선 지급하고 모든 카드를 받은 뒤 전체 카드 풀을 다시 사용한다.
- 받은 카드를 보관하거나 나중에 홈의 카드 보관함에서 간직한다.
- 카드 앞/뒤 뒤집기와 상세 보기, 수집 상태 유지를 지원한다.
- 카드 스프라이트는 500KB 이하 WebP로 제공하고 홈에서 낮은 우선순위로 미리 불러온다.

## 9. 친구

- 로그인한 사용자는 이메일 전체 주소 또는 닉네임 앞부분으로 다른 사용자를 찾는다.
- 검색 결과에는 전체 이메일 대신 일부를 가린 이메일을 표시한다.
- 친구 요청을 보내고 상대는 받은 요청을 수락하거나 거절한다.
- 서로 동시에 요청한 경우 친구 관계로 연결한다.
- 내 친구, 받은 요청, 보낸 요청을 나누어 보고 친구 관계를 해제한다.
- 내 닉네임을 2~20자로 설정하며 모든 친구 API는 서버에서 로그인 사용자와 관계 권한을 검증한다.
- 친구 화면은 작은 내 프로필 줄, 검색창, 친구 목록 순서로 배치하고 친구 수를 상단에 표시한다.
- 친구 목록은 한 줄에 한 명씩 작은 원형 아바타·닉네임·마스킹된 이메일을 담은 세로 리스트로 표시하고, 목록 영역 안에서 스크롤한다.
- 한 친구 행은 56~68px 높이를 지키고 긴 닉네임과 이메일은 말줄임으로 자른다.
- 친구 행 전체를 눌러 상세 모달을 열고, 상세 모달에서만 친구를 해제한다.
- 친구 해제는 확인 모달을 한 번 더 거치며 위험 동작은 주요 CTA보다 작게 표시한다.
- 받은 요청은 친구 목록 위 컴팩트 섹션에서 수락·거절하고, 보낸 요청은 `수락 대기`로 표시한다.
- 빈 목록, 검색 결과 없음, 로딩, 오류 상태를 각각 구분해 안내한다.
- 오류 문구는 해당 입력이나 동작 근처에 표시하고, 성공 알림은 공용 토스트로 알린다.

- 친구 상세 모달의 주요 동작은 `선물하기`와 `차단하기` 두 가지이며, `친구 해제`는 보조 동작으로 남긴다.
- `선물하기`는 그 친구를 미리 선택한 상태로 말씀 선물 제작 흐름을 연다.
- `차단하기`는 선물하기보다 약한 위험 동작으로 표시하고, 확인 모달을 거친 뒤에만 실행한다.
- 차단 확인 모달은 친구 목록·검색·친구 요청·새 선물이 막힌다는 점과 이미 주고받은 선물은 그대로 남는다는 점을 함께 설명한다.
- 차단에 성공하면 상세·확인 모달을 닫고 목록을 새로고침하며, 성공은 공용 토스트로, 실패는 확인 모달 안 인라인 오류로 알린다.

## 9-2. 차단 목록 관리

- 친구 화면 아래에 작고 눈에 띄지 않는 `차단한 친구 관리` 진입점을 둔다.
- 차단한 사용자는 친구 목록, 친구 검색, 받은 요청, 보낸 요청에서 모두 제외한다.
- 차단 목록 모달에서 사용자마다 `차단 해제`를 제공하고, 비었을 때 빈 상태를 보여준다.
- 차단을 해제해도 친구 관계는 자동으로 복구하지 않으며 다시 친구 요청을 보내야 친구가 된다.

## 9-3. 차단 데이터와 서버 정책

- 차단은 `friend_blocks` 테이블에 영구 저장하고 `blocker_key + blocked_key`에 유니크 인덱스를 둔다.
- 로그인한 사용자만 차단·차단 해제를 할 수 있고 자기 자신은 차단할 수 없다.
- 차단하면 그 사용자 쌍의 친구 관계와 양방향 대기 중 친구 요청을 함께 지운다.
- 한쪽이라도 차단한 사이라면 서로 검색에서 제외하고, 친구 요청·수락, 선물 초안 생성, 기존 선물 전송, 선물 초안 전송을 모두 거절한다.
- 차단 검증은 클라이언트가 아니라 관련 서버 API마다 다시 수행한다.
- 이미 주고받은 선물은 지우지 않고 각자의 선물함에 남기며, 차단된 사용자도 기존 선물을 열고 재생할 수 있다.

## 9-1. 공용 친구 선택 모달

- 친구를 골라야 하는 모든 흐름은 같은 `FriendPickerModal` 컴포넌트를 쓴다.
- 말씀 선물하기의 친구 선택은 페이지형 단계가 아니라 이 모달로 띄운다.
- 모달 한 화면에 검색창, 내 친구 전체 목록, 검색 결과, 선택 상태를 함께 보여준다.
- 검색은 기존 `/api/friends`를 그대로 써서 닉네임 앞부분 또는 정확한 이메일로 찾고, 친구인 사용자만 고를 수 있다.
- 선택한 친구 행을 강조하고, 선택 전에는 `이 친구 선택` 버튼을 비활성화한다.
- 닫기 버튼, ESC, 바깥 클릭으로 닫으며 목록은 모달 안에서만 스크롤한다.
- 친구 선택 모달과 친구 상세·해제 확인창은 온보딩 오버레이와 떠 있는 버튼보다 위에 표시한다.

## 10. 말씀 선물

- 듣기 탭에서 현재 이어듣기 가능한 녹음 묶음을 친구에게 선물한다.
- 매일 말씀 읽기는 여정 전체, 자유 녹음은 현재 장의 녹음 묶음을 보낸다.
- 선물에는 보내는 순간 선택한 BGM과 음량이 함께 저장된다.
- 선물 음원은 R2에 별도로 복사하므로 보낸 사람이 원본을 수정하거나 삭제해도 받은 선물은 유지된다.
- 받은 선물은 선물 탭에서 순서대로 이어듣고, 절 목록에서 원하는 위치로 이동한다.
- 받은 선물과 선택 BGM을 ZIP으로 다운로드하거나 확인 후 영구 삭제한다.
- 선물 생성·목록·재생·다운로드·삭제는 서버에서 로그인 사용자, 친구 관계, 발신자 소유권, 수신자 권한을 검증한다.

## 11. 말씀 골라 선물하기

- 홈의 큰 메인 메뉴 `말씀 선물하기`로 들어간다. 안내 문구는 `오늘, 마음에 떠오른 말씀을 소중한 사람에게 목소리로 전해 보세요.`이고 CTA는 `말씀 골라 선물하기`이다.
- 선물 제작은 홈의 `말씀 선물하기`에서 시작한다. 성경 읽기와 진행 중 말씀 여정에는 선물 제작 진입 버튼을 두지 않는다.
- 순서는 받을 친구 선택 → 선물할 말씀 선택 → 선택한 순서대로 녹음 → 전체 미리 듣기와 구절별 재녹음 → BGM과 음량 선택 → 바로 선물하기이다.
- 선물할 말씀 범위는 특정 구절, 한 장 전체, 여러 장, 여러 권, 진행 중인 말씀 여정의 녹음 중에서 고른다.
- 진행 중인 말씀 여정을 고르면 이미 녹음한 음원을 그대로 쓰므로 새로 녹음하지 않는다.
- 선물용 녹음은 새 읽기 여정이나 `○○ 녹음` 그룹을 만들지 않는다. 전송 전까지 임시 `선물 초안`으로만 관리한다.
- 선물 초안의 녹음은 보관함 목록, 내 말씀 여정, 자유 녹음 목록, 말씀 카드 보상에 나타나지 않는다.
- 한 선물 초안은 최대 500절까지 담고, 그보다 넓은 범위는 범위를 줄여 달라고 안내한다.
- 녹음은 선택한 말씀 순서대로 한 절씩 진행하고, 다음에 녹음할 절로 자동 이동한다.
- 미리 듣기는 선택한 순서대로 이어 재생하며, 마음에 들지 않는 절만 골라 다시 녹음하면 기존 음원을 즉시 교체한다.
- 모든 절을 녹음하기 전에는 선물을 보낼 수 없다.
- 초안은 나중에 이어서 만들 수 있고, 직접 버리면 초안과 초안 음원을 함께 지운다.
- 선물 초안 생성·조회·녹음·재생·전송·삭제는 서버에서 로그인 사용자, 친구 관계, 초안 소유권을 검증한다.
- 보내는 순간 기존 선물 규칙을 그대로 따른다. 친구 관계를 다시 확인하고, 친구가 이전 선물을 열지 않았으면 보내지 않는다.
- 전송에 성공하면 초안 음원을 그대로 선물 음원으로 넘겨 선물 탭의 재생, ZIP 다운로드, 삭제, 감사 메시지 기능을 그대로 사용한다.

## 12. 말씀 선물 도착 모달

- 앱 시작, 창 포커스 복귀, 화면 재활성화, 15초 주기로 아직 확인하지 않은 새 선물을 전역에서 감지한다.
- `arrival_seen_at`과 `opened_at`을 분리해 새로 도착함, 도착 안내 확인함, 선물 열어봄 상태를 구분한다.
- 일반 녹음 화면과 선물 녹음 스튜디오에서는 도착 이벤트를 보관하고, 해당 화면과 녹음 관련 모달을 모두 벗어난 뒤 표시한다.
- 다른 완료·카드·삭제 모달이 떠 있을 때도 겹쳐 띄우지 않고 기존 경험이 끝난 다음 표시한다.
- 여러 선물이 도착하면 모달을 연속으로 띄우지 않고 발신자와 개수를 하나의 도착 경험으로 요약한다.
- 단일 선물의 `선물 열어보기`는 도착 확인과 개봉을 함께 저장하고, 받은 선물함에서 방금 연 선물을 펼친다.
- 여러 선물의 CTA는 도착 확인을 한 번에 저장한 뒤 받은 선물함으로 이동해 각각 열도록 한다.
- 닫기 또한 도착 안내 확인으로 저장해 다음 앱 실행에서 같은 모달을 반복하지 않는다.

## 13. 말씀 선물 편지

- 두 선물 전송 경로 모두 편지 없이 보내기, 최대 500자의 텍스트 편지, 최대 90초·5MB의 음성 편지 중 하나를 선택한다.
- 음성 편지는 녹음 후 재생, 재녹음, 확정을 거쳐 선물과 함께 R2에 저장한다.
- 수신 목록은 쪽지의 존재와 종류만 알리고, `쪽지 열어보기` 전에는 텍스트 내용과 음성 스트리밍을 모두 숨긴다.
- 쪽지를 직접 열면 별도의 `letter_opened_at`을 기록하고 텍스트 또는 수신자 전용 음성 플레이어를 표시한다.
- 음성 쪽지는 로그인한 수신자가 쪽지를 연 뒤에만 구간 스트리밍할 수 있으며 private/no-store로 제공한다.
- 쪽지를 확인한 뒤 같은 선물 카드에서 기존 말씀 이어듣기, BGM, 다운로드 흐름을 계속 사용한다.
