# 말씀유산 기능 인벤토리와 회귀 테스트 기준

이 문서는 현재 제품 동작의 기준선이다. 기능을 추가하거나 정책을 변경할 때 먼저 이 문서와 테스트를 갱신하고, 실패하는 테스트를 확인한 뒤 구현한다.

## 1. 홈과 전역 탐색

- 사이트 진입 및 새로고침 시 항상 홈에서 시작한다.
- 홈에서 라이트/다크 모드를 전환하며 선택은 브라우저에 유지된다.
- 홈에서 `내 방식대로 자유롭게`, `매일 말씀 읽기 시작하기`, `내 말씀 여정`, `내 카드 보관함`으로 이동한다.
- 앱 상단에서 홈, 녹음, 듣기로 이동한다.
- `내 말씀 여정`에는 실제 녹음이 하나 이상 남은 여정만 표시한다.

## 2. 말씀 여정

- 1주/2주 템플릿과 초급·중급·고급 분량을 선택한다.
- 직접 성경 범위와 여정 이름을 정해 맞춤 여정을 만든다.
- 같은 여정의 전체 일정과 날짜별 완료 상태를 확인한다.
- 매일 읽기는 하루에 최대 한 단계만 진행한다.
- 오늘 분량이 미완료면 다음 날짜에도 같은 분량이 유지되고 이후 일정과 종료일이 밀린다.
- 오늘 완료해도 같은 날 다음 분량으로 넘어가지 않고 다음 날짜에 전환된다.

## 3. 자유 녹음과 성경 선택

- 구약 39권/신약 27권과 총 66권 전체를 탐색하고 검색한다.
- 책, 장을 선택하고 본문 전체를 미리 확인한 뒤 녹음을 시작한다.
- 진행 중인 장을 별도 스타일로 표시한다.
- 같은 성경책의 여러 장은 하나의 `○○ 녹음` 여정으로 묶는다.
- 내 말씀 여정에서 책을 열면 책 선택 없이 해당 책의 장만 선택하고 확인 후 녹음 화면으로 이동한다.

## 4. 녹음

- 기본 녹음은 현재 절부터 이어 녹음이다.
- `다음 절`로 경계를 기록하고 `여기까지 녹음`하면 현재 절까지 저장한다.
- 이어 녹음 결과를 절별 파일로 잘라 저장한다.
- 이어 녹음으로 기존 절에 진입하면 해당 절 녹음을 새 결과로 덮어쓴다.
- 저장된 절은 개별 듣기와 `이 절 수정`을 제공한다.
- 절별 수정은 확인 없이 기존 파일을 즉시 삭제하고 같은 절 재녹음으로 진입한다.
- 현재 장 전체 새 녹음은 삭제 확인 후 모든 절을 지우고 1절부터 시작한다.
- 녹음 중 마이크 권한, 지원하지 않는 브라우저, 저장 실패 상태를 안내한다.
- 모바일 녹음을 위해 Opus 우선 포맷, 자동 음량 보정, 리미터와 선택 리버브를 적용한다.

## 5. 음향과 BGM

- 원음/따뜻하게/예배당 음색을 선택한다.
- BGM 없음 및 여러 BGM을 선택하고 미리 듣는다.
- 재생·일시정지·정지는 각각 상태가 구분되며 정지 후 재생은 처음부터 시작한다.
- 녹음 중 BGM이 재생 중이면 이어폰 사용 경고를 제공한다.
- BGM 볼륨을 녹음 화면과 이어듣기 화면에서 조절한다.

## 6. 듣기 보관함

- 여정에 속한 녹음만 책/장/절 단위로 묶어 표시한다.
- 절별 듣기는 목소리만 재생한다.
- 장 전체 이어듣기는 절 순서대로 재생하며 재생 모달의 본문도 절에 맞춰 바뀐다.
- 이어듣기 목록 아이콘으로 녹음된 절을 열고 원하는 절로 점프한다.
- 이어듣기 중 BGM 선택, 볼륨 조절, 정지가 가능하다.
- 다음 미녹음 절로 포커스하고 장/절 목록도 해당 위치를 보여준다.

## 7. 녹음 데이터와 보안 경계

- 기기별 소유자 키로 보관함 목록, 재생, 교체, 삭제 권한을 분리한다.
- 녹음 메타데이터는 D1, 음성 파일은 R2에 저장한다.
- 같은 여정·책·장·절에 새 파일을 저장하면 기존 파일을 원자적으로 교체한다.
- 한 파일은 최대 25MB이며 잘못된 장·절·본문은 거부한다.
- 오디오 응답은 비공개·비캐시 헤더를 사용한다.

## 8. 말씀 카드

- 매일 말씀 분량 완료 시 말씀 카드를 지급한다.
- 자유 녹음은 보상 대상이 아니며 매일 말씀 여정에만 지급한다.
- 같은 여정의 같은 일차에는 카드를 한 번만 지급한다.
- 아직 받지 않은 카드를 우선 지급하고 모든 카드를 받은 뒤 전체 카드 풀을 다시 사용한다.
- 받은 카드를 보관하거나 나중에 홈의 카드 보관함에서 간직한다.
- 카드 앞/뒤 뒤집기와 상세 보기, 수집 상태 유지를 지원한다.

## 자동 회귀 테스트 범위

- `app/bible-metadata.test.ts`: 66권 데이터 파일, 장 수, 절 수, 빈 본문 검증.
- `lib/reading-policy.test.ts`: 결석 시 일정 밀림, 동일 날짜 고정, 하루 한 단계, 마지막 날 상한 검증.
- 빌드·정적 검사: TypeScript, oxlint, 프로덕션 번들, diff whitespace.
- 브라우저 스모크: 홈 시작, 테마, 주요 진입점, 성경/장 선택, 여정 목록, 녹음/듣기 기본 UI.

마이크 입력 자체, 실제 음질의 주관 평가, YouTube 외부 재생 성공은 브라우저·네트워크·하드웨어 의존 항목이므로 실제 기기 수동 검증도 병행한다.
