## 자동 테스트

- 일정 정책 6건 통과: 최초 1일차, 정상 전진, 결석 고정, 여러 날 결석 시 1단계 제한, 당일 재전진 방지, 마지막 날 상한.
- 말씀카드 보상 정책 5건 통과: 최초 지급, 일차별 중복 방지, 미보유 카드 우선, 전체 수집 후 재순환, 간직하기 상태 전환.
- 카드 이미지 성능 예산 3건 통과: 모든 스프라이트 WebP 및 파일당 500KB 이하.
- 성경 데이터 2건 통과: 66권 고유 코드, 모든 책의 JSON·장 수·절 수·빈 본문 전수 검증.
- API 권한 스모크 통과: 소유자 키 없는 보관함 목록과 오디오 요청 모두 HTTP 401.
- TypeScript, oxlint, 프로덕션 빌드, diff whitespace 검사를 배포 전 필수 게이트로 사용한다.

`pnpm lint:all`에는 현재 제품에서 사용하지 않는 생성형 `components/ui`와 `hooks/use-mobile.ts`의 기존 접근성·React Compiler 경고 18건이 남아 있다. 제품 회귀 게이트인 `pnpm lint`는 실제 앱·도메인·DB 코드에 적용하며, 전체 템플릿 부채는 별도 명령으로 계속 추적한다.
