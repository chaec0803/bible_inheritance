# 말씀유산 전체 수동 QA 시나리오

이 문서는 두 계정(A: 보내는 사람, B: 받는 사람)으로 제품의 주요 기능을 처음부터 끝까지 눈으로 확인하기 위한 체크리스트다.

## 테스트 준비

- Chrome 또는 앱 내 브라우저에서 `http://localhost:3000`을 연다.
- 계정 A와 계정 B를 서로 다른 브라우저 프로필 또는 일반 창/시크릿 창에 로그인한다.
- 마이크 권한을 허용한다.
- 짧은 검증을 위해 녹음 범위는 `창세기 1장 1절부터 2절까지`를 사용한다.
- 삭제 검증은 가장 마지막에 한다.

## 1. 로그인·홈·전역 이동

- [x] 계정 A로 로그인하면 홈이 열린다.
- [x] 새로고침해도 홈에서 시작한다.
- [x] 다크/라이트 모드를 바꾸고 새로고침하면 선택이 유지된다.
- [x] 홈에 `말씀 선물하기`, `성경 읽기`, `추천 매일 말씀 읽기 시작하기`, `내 말씀 여정`, `내 카드 보관함`이 모두 보인다.
- [x] 하단 메뉴의 `녹음`, `듣기`, `선물`, `친구`가 각각 정상 이동한다.
- [x] 각 서브화면의 뒤로가기/홈으로가 직전 화면 또는 홈으로 정상 복귀한다.
- [x] 모바일 폭에서 내용이 잘리거나 겹치지 않고, 하단 메뉴와 토스트가 서로 가리지 않는다.

## 2. 친구 맺기(A ↔ B)

### 계정 A

- [x] `친구`에서 닉네임을 2~20자로 저장한다.
- [x] 1글자 검색 시 2자 이상 입력 안내가 보인다.
- [x] 계정 B의 전체 이메일 또는 닉네임 앞부분으로 검색한다.
- [x] 검색 결과의 이메일이 일부 가려져 보인다.
- [x] `친구 요청`을 누르면 `요청 보냄` 또는 보낸 요청 목록에 나타난다.

### 계정 B

- [x] 새로고침 또는 친구 화면 재진입 후 `받은 요청`에 계정 A가 보인다.
- [x] 요청을 수락하면 `내 친구`에 계정 A가 나타난다.

### 계정 A 재확인

- [x] 새로고침 후 `내 친구`에 계정 B가 나타난다.
- [x] 친구 검색, 받은 요청, 보낸 요청, 내 친구 영역이 빈 상태에서도 자연스럽게 보인다.
- [x] 친구 해제는 삭제 시나리오에서 확인한다.

## 3. 성경 읽기 범위 선택

- [x] 홈 → `성경 읽기`로 들어간다.
- [x] `한 장 읽기`, `범위 지정`, `구약 통독`, `신약 통독`, `성경 통독` 옵션이 보인다.
- [x] `범위 지정`을 선택한다.
- [x] 시작과 끝 모두 `성경책`이 한 행, `장`과 `절`이 다음 행에 보여 긴 책 이름도 잘리지 않는다.
- [x] 시작 성경책을 바꾸면 장·절이 그 책의 첫 장·첫 절로 맞춰진다.
- [x] 끝 성경책을 바꾸면 장·절이 그 책의 마지막 장·마지막 절로 맞춰진다.
- [x] 시작이 끝보다 뒤인 범위는 시작할 수 없거나 이해 가능한 오류가 보인다.
- [x] `창세기 1장 1절부터 2절까지`로 설정하고 읽기를 시작한다.
- [x] 본문에 1절과 2절 말씀이 실제로 보인다.

## 4. 녹음·이어 녹음·절별 수정

- [x] 기본 동작이 `1절부터 이어 녹음`으로 보인다.
- [x] BGM 세 곡과 `음악 없음`이 보이고 재생·일시정지·정지 및 음량 변경이 된다.
- [x] 이어폰 경고와 마이크 권한 안내가 읽기 쉽게 보인다.
- [x] 녹음을 시작하고 1절을 읽은 뒤 `다음 절`로 경계를 만든다.
- [x] 2절을 읽고 `여기까지 녹음`으로 저장한다.
- [x] 1절·2절이 각각 녹음 완료 상태로 표시된다.
- [x] 이어 녹음으로 나눈 각 절이 `audio/mp4`로 저장되고 160kbps 수준의 작은 용량인지 확인한다.
- [x] 새로고침 후에도 저장 완료 상태가 유지되고 MP4 녹음이 실제 재생된다.
- [x] 완료 전에는 `이 절 수정`이 보이고 실제로 해당 절만 다시 녹음할 수 있다.
- [x] 수정한 절을 재생하면 새 음성이 들리고 다른 절은 그대로다.
- [x] `이 절 수정`을 누르면 기존 녹음이 즉시 삭제되고 같은 절의 다시 녹음 상태로 전환된다.
- [x] `처음부터 다시 녹음`은 확인창을 거친다. 취소하면 기존 녹음이 유지된다.
- [x] 녹음 완료만으로 여정이 자동 완료 처리되지 않는다.

## 5. 듣기 보관함·명시적 완료

- [x] `듣기`로 이동하면 방금 녹음한 묶음이 범위 단위로 보인다.
- [x] 절 하나 재생 시 목소리만 들린다.
- [x] `전체 이어듣기`를 누르면 1절 → 2절 순서로 재생되고 본문도 현재 절에 맞춰 바뀐다.
- [x] 목록 버튼에서 원하는 절부터 재생할 수 있다.
- [x] 이어듣기 모달의 일시정지·계속 듣기·종료가 모두 동작한다.
- [x] BGM과 음량을 바꾸면 전체 이어듣기에 반영된다.
- [x] `여정 저장하기`를 누르면 `여정을 완료하시겠습니까?` 확인창이 나타난다.
- [x] 취소하면 녹음 화면에서 계속 수정할 수 있다.
- [x] 다시 눌러 `완료`하면 완료된 말씀으로 이동한다.
- [x] 완료된 말씀은 작은 아이콘/카드로 보이고 완료일과 범위가 보인다.
- [x] 완료된 말씀을 누르면 이어듣기와 같은 형식의 모달이 열린다.
- [x] 완료 후에는 녹음 화면과 분리되어 절별 수정·다시 녹음이 불가능하다.

## 6. 완료된 말씀 여러 개 만들기·정렬·선택

- [x] 위 과정을 다른 짧은 범위로 한 번 더 반복해 완료된 말씀을 2개 만든다.
- [x] 완료 목록에서 `완료일순`과 `이름순` 정렬이 정상 동작한다.
- [x] 각 완료 카드 내부의 작은 체크박스로 하나 또는 여러 개를 선택할 수 있다.
- [x] 선택 단위가 절 하나가 아니라 완료된 말씀 묶음 전체임을 확인한다.
- [x] 2개 선택 시 버튼에 `선택한 말씀 2개 선물하기`가 보인다.

## 7. 추천 여정·나만의 읽기 계획·말씀 카드

- [x] 홈 → `추천 매일 말씀 읽기 시작하기`로 들어간다.
- [x] 추천 여정에서 1주/2주와 난이도 또는 추천 항목을 확인한다.
- [x] `나만의 읽기 계획`에서 한 장/범위/구약/신약/성경 통독 범위를 선택할 수 있다.
- [x] 직접 만든 여정의 이름과 완료 기간을 지정해 시작한다.
- [x] 오늘 분량을 일부만 녹음하고 나갔다 돌아오면 같은 위치에서 이어진다.
- [x] 오늘 분량을 완료하면 같은 날 다음 날 분량으로 넘어가지 않는다.
- [x] 하루 분량 완료 시 말씀 카드 보상이 한 번만 나타난다.
- [x] 카드 앞/뒤를 뒤집고 상세 내용을 확인한다.
- [x] `내 카드로 간직하기` 후 홈 → `내 카드 보관함`에서 카드가 보인다.
- [x] 카드를 누르면 상세 보기가 열린다.

## 8. 홈에서 새 말씀 선물 만들기

### 계정 A

- [x] 홈 → `말씀 선물하기` → `말씀 골라 선물하기`로 들어간다.
- [x] `진행 중인 선물`이 기존 초안과 분리된 컴포넌트로 보인다.
- [x] 받을 친구로 계정 B를 선택한다.
- [x] `한 장 읽기`와 `범위 지정`의 UI와 설명이 서로 구분된다.
- [x] 짧은 범위를 선택해 초안을 만든다.
- [x] 초안이 일반 여정·듣기 보관함·카드 보관함에는 나타나지 않는다.
- [x] 녹음 화면에 현재 말씀 본문이 분명하게 보인다.
- [x] 기본은 이어 녹음이며, 모든 절을 녹음하기 전에는 전송할 수 없다.
- [x] 중간에 홈으로 나갔다가 `진행 중인 선물`에서 같은 초안을 이어서 연다.
- [x] 미리 듣기에서 전체가 선택 순서대로 재생된다.
- [x] `절별 수정`으로 한 절만 다시 녹음하고 새 음성으로 교체됐는지 듣는다.
- [x] `처음부터 다시 녹음` 확인창에서 취소 동작도 확인한다.
- [x] BGM을 미리 듣고 음량을 변경한다.
- [x] 선물 이름을 입력한다.
- [x] `바로 선물하기`를 누르면 `선물을 보냈습니다!` 확인 모달이 열리고, 확인 후 방금 보낸 선물이 펼쳐진 `보낸 선물` 탭으로 이동한다.
- [x] 성공 후 초안이 `진행 중인 선물`에서 사라진다.

## 9. 완료된 말씀을 하나 또는 여러 개 선물하기

### 계정 A

- [x] 홈 → `내 말씀 여정`의 완료 목록으로 이동한다.
- [x] 완료 카드 1개를 체크하고 선물 버튼을 누른다.
- [x] 계정 B, 선물 이름, BGM/음량을 선택해 전송한다.
- [ ] 친구 2명 이상을 누적 선택하면 선택 칩과 인원수가 보이고, 칩의 닫기를 누르면 해당 친구만 해제된다.
- [ ] 여러 명에게 보내면 각 수신자의 받은 선물함에 독립된 선물이 생기며 한 사람의 개봉·삭제가 다른 사람에게 영향을 주지 않는다.
- [x] 계정 B가 아직 열지 않은 상태에서 같은 친구에게 다시 보내 본다.
- [x] `친구가 이전 선물을 아직 열지 않았어요` 오류가 가려지지 않는 모달로 보인다.
- [x] 모달의 닫기와 `선물함 확인하기`가 동작한다.

### 계정 B

- [x] `선물` → `받은 선물`의 `안 열어본 선물`에 새 선물이 나타난다.
- [x] 열기 전에는 제목/내용이 숨겨지고 발신자와 받은 날짜가 보인다.
- [x] `선물 열기`를 누르면 `열어본 선물` 섹션으로 이동한다.

### 계정 A

- [x] `선물` → `보낸 선물`에서 상태가 `열어봄`으로 갱신된다.
- [x] 이제 완료된 말씀 2개를 체크해 하나의 선물로 전송할 수 있다.
- [x] 전송 결과가 절 조각이 아니라 선택한 완료 말씀 묶음들로 구성되는지 확인한다.

## 10. 받은 선물 듣기·상세·감사·다운로드

### 계정 B

- [x] 열린 선물의 작은 카드를 눌러 상세를 펼친다.
- [x] 발신자, 선물 이름, 받은 날짜, 녹음 수, BGM이 보인다.
- [x] `이어듣기`가 일반 이어듣기와 같은 모달 UI로 열린다.
- [x] 본문, 현재 위치, 목록, 일시정지·계속 듣기·종료가 정상 동작한다.
- [x] 목록에서 중간 말씀부터 들을 수 있다.
- [x] BGM 음량 변경이 재생에 반영된다.
- [x] `MP4 다운로드` 후 `.mp4` 파일이 실제 재생된다.
- [x] 감사 인사 템플릿 또는 직접 입력으로 감사 인사를 보낸다.

### 계정 A

- [x] 보낸 선물 상세에 받은 사람, 보낸 날짜, 개봉 시간, 감사 인사가 보인다.
- [x] 화면 포커스 복귀 또는 최대 15초 이내 상태가 갱신된다.

## 11. 토스트·모달·오류 가시성

- [x] 친구, 저장, 녹음, 선물 관련 토스트가 배경과 충분히 대비된다.
- [x] 토스트가 하단 메뉴나 모달 뒤에 가려지지 않는다.
- [x] 토스트는 약 4초 후 자동으로 사라진다.
- [x] 같은 동작을 다시 하면 새 토스트가 다시 나타나고 또 사라진다.
- [x] 모든 확인/오류 모달이 의도된 위치(중앙 또는 하단 중앙)와 모바일 화면 안에 완전히 보인다.
- [x] 모달을 닫으면 뒤 화면의 스크롤과 클릭이 정상 복구된다.

## 12. 말씀 선물에 편지 덧붙이기

### 계정 A

- [ ] 기존 선물하기와 선물 스튜디오 모두 `편지 없이`, `텍스트 편지`, `음성 편지` 중 하나를 선택할 수 있다.
- [ ] 편지 없이 선택하면 기존과 동일하게 선물이 전송된다.
- [ ] 텍스트 편지를 작성해 보내고 선물 내용이나 완료 안내에 편지 내용이 잘못 노출되지 않는다.
- [ ] 음성 편지를 녹음한 뒤 재생, 재녹음, 확정이 모두 동작한다.
- [ ] 90초가 되면 녹음이 자동 종료되고, 5MB를 넘는 음성은 전송되지 않는다.

### 계정 B

- [ ] 편지가 포함된 선물 상세에 `함께 온 쪽지가 있어요`가 보이지만 내용은 처음부터 노출되지 않는다.
- [ ] `쪽지 열어보기`를 누른 뒤에만 텍스트 편지 내용이 보인다.
- [ ] 음성 쪽지는 연 뒤에만 플레이어가 나타나고 재생·탐색이 동작한다.
- [ ] 쪽지를 확인한 뒤 같은 카드에서 말씀 `이어듣기`로 자연스럽게 이어진다.
- [ ] 앱을 새로고침해도 이미 연 쪽지는 열린 상태를 유지한다.

### 권한·정리

- [ ] 다른 계정이나 발신자가 수신자의 음성 쪽지 URL을 직접 열어도 재생되지 않는다.
- [ ] 받은 선물을 삭제하면 전용 음성 쪽지도 함께 정리되며 보낸 사람의 선물함에는 삭제 사실이 표시되지 않는다.

## 13. 삭제·격리·복구 불가 확인 (마지막에 수행)

- [x] 진행 중 선물 초안의 작은 삭제 버튼을 누르면 확인 후 초안이 사라진다.
- [x] 진행 중 말씀 읽기를 삭제하면 그 여정과 관련 녹음이 목록에서 사라진다.
- [x] 완료된 말씀 모달에서 삭제하면 완료 목록에서 사라진다.
- [x] 받은 선물을 삭제하면 계정 B의 선물함에서 사라진다.
- [x] 계정 B가 받은 선물을 삭제해도 계정 A의 보낸 선물에는 삭제 사실이 표시되지 않는다.
- [x] 계정 A에서 `보낸 선물 삭제`를 해도 계정 B가 가진 선물은 유지된다.
- [x] 친구 해제 후 새 선물 전송이 차단된다.
- [x] 각 삭제 확인창에서 취소 시 데이터가 유지되고, 확정 시 복구 불가 안내와 결과가 일치한다.

## 14. 재로그인·다른 기기·회귀 확인

- [x] 로그아웃 후 같은 계정으로 로그인하면 여정, 녹음, 완료 말씀, 카드, 친구, 선물이 유지된다.
- [x] 계정 B 데이터가 계정 A에서 보이지 않고 반대도 동일하다.
- [x] 브라우저 뒤로가기/앞으로가기를 반복해도 빈 화면이나 잘못된 중첩 화면이 나오지 않는다.
- [x] 콘솔에 새로운 runtime error가 없다.
- [x] 오디오 요청에서 `Failed to load because no supported source was found`가 발생하지 않는다.

## 발견 사항 기록 형식

각 실패는 다음을 함께 기록한다.

- 시나리오 번호와 체크 항목
- 계정 A/B 중 어느 계정인지
- 현재 URL hash
- 기대 결과와 실제 결과
- 스크린샷 또는 짧은 화면 녹화
- 재현 빈도(항상/간헐적/한 번)
- 브라우저와 기기
